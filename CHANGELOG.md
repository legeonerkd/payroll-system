# Changelog

Все значимые изменения в проекте PayrollSystem документируются в этом файле.

## [1.9.0] - 2026-05-27

### ✨ Добавлено

#### Автоматическое обновление списка сотрудников
- **Синхронизация без перезагрузки** - при добавлении нового сотрудника на вкладке "Employees", список автоматически обновляется на вкладке "Payroll"
- **Сохранение текущего выбора** - если сотрудник был выбран, выбор сохраняется после обновления списка
- **Метод `refresh_employees()`** - добавлен публичный метод для обновления списка сотрудников в PayrollTab

#### Автоматическое сохранение истории отработанных часов
- **База данных часов** - все отработанные часы автоматически сохраняются в таблицу `work_hours` при генерации PDF
- **Метод `save_hours_batch()`** - массовое сохранение часов за весь период одной операцией
- **Связь с сотрудниками** - каждая запись часов связана с конкретным сотрудником через `employee_id`
- **Предотвращение дубликатов** - использование UNIQUE constraint для комбинации (employee_id, work_date)

#### Экспорт истории отработанных часов
- **Новое меню "Export"** - добавлен пункт меню для экспорта данных
- **Окно "Export work hours"** - красивое окно с таблицей всех отработанных часов
- **Экспорт в CSV** - возможность выгрузить всю историю в CSV файл с колонками:
  - Employee (имя сотрудника)
  - Date (дата работы)
  - Hours (количество часов)
  - Rate (€/h) (ставка)
  - Amount (€) (сумма за день)
- **Статистика** - отображение общего количества записей, часов и суммы
- **Zebra-стиль таблицы** - удобное чередование цветов строк
- **Открытие файла** - возможность сразу открыть экспортированный CSV файл

### 🔧 Улучшено

#### Database (db.py)
- **Метод `get_all_hours()`** - получение всей истории часов с JOIN к таблице employees
- **Метод `export_hours_to_csv()`** - экспорт данных в CSV файл с правильным форматированием
- **Метод `save_hours_batch()`** - оптимизированное сохранение множества записей

#### PayrollTab
- **Улучшенный `_load_employees()`** - сохранение текущего выбора при обновлении
- **Метод `_save_hours_to_database()`** - автоматическое сохранение часов при генерации PDF
- **Интеграция с БД** - все часы сохраняются при создании отчёта (Preview, Save, Print)

#### Главное приложение (app.py)
- **Callback `_on_employees_changed()`** - централизованная обработка изменений в списке сотрудников
- **Обновление PayrollTab** - автоматический вызов `refresh_employees()` при изменении данных

### 📝 Описание
Версия 1.9.0 значительно улучшает пользовательский опыт за счёт автоматической синхронизации данных между вкладками и добавляет полноценную систему учёта и экспорта истории отработанных часов. Теперь все часы сохраняются в базе данных и могут быть экспортированы в удобном формате CSV.

## [1.8.3] - 2026-05-26

### ✨ Добавлено

#### Удержания для Custom Rate сотрудников
- **Удержания Utilities и Rental** - теперь применяются к сотрудникам с кастомной ставкой
- **Универсальная логика** - все типы сотрудников (Fixed и Custom Rate) поддерживают полный функционал удержаний
- **Корректный расчёт** - Net = Gross - Housing - Utilities для всех типов ставок

#### Автомасштабирование PDF-отчётов
- **Динамическое масштабирование таблицы** - автоматическая адаптация размера шрифта и отступов в зависимости от количества рабочих дней
- **Гарантия размещения на одной странице** - любой месячный отчёт (до 31 дня) помещается на одном листе A4
- **Три режима отображения**:
  - 1-15 дней: стандартный режим (шрифт 9pt, отступы 4px)
  - 16-25 дней: компактный режим (шрифт 8pt, отступы 3px)
  - 26-31 день: максимальная плотность (шрифт 7pt, отступы 2px)

### 🔄 Изменено

#### Payroll Service
- **Функция `calculate_custom_payroll()`** - теперь применяет удержания housing и utilities
- **Расчёт net amount** - учитывает все удержания для custom rate сотрудников
- **Комментарий в коде** - обновлён с "NO DEDUCTIONS" на "DEDUCTIONS APPLY"

#### Report Service
- **Функция `_render_pdf_to_file()`** - добавлена логика динамического масштабирования
- **Параметры таблицы** - размер шрифта и padding теперь вычисляются на основе количества строк

### 🧪 Тесты
- **Обновлены существующие тесты** - исправлены сигнатуры функций
- **Добавлен `test_fixed_payroll_with_deductions()`** - проверка удержаний для fixed rate
- **Обновлён `test_custom_payroll_with_deductions()`** - проверка удержаний для custom rate
- **Все 6 тестов проходят успешно** ✅

### 📝 Описание
Версия 1.8.3 устраняет несоответствие в логике удержаний между типами сотрудников и улучшает читаемость PDF-отчётов за счёт умного масштабирования, обеспечивая размещение любого месячного отчёта на одной странице.

## [1.8.2] - 2026-04-06

### 🔄 Изменено

#### Payroll Service - Логика удержаний
- **Fixed Rate (8€/h)** - теперь удержания ПРИМЕНЯЮТСЯ (housing + utilities вычитаются из gross)
- **Custom Rate** - теперь удержания НЕ применяются (net = gross, без вычетов)

### 📝 Описание
Изменена логика расчета зарплаты: удержания за коммунальные услуги и аренду теперь применяются только к фиксированной ставке 8€/час, а при использовании кастомной ставки сотрудника удержания не применяются.
