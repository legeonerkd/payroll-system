## ✨ Новые возможности

### 🔄 Автоматическая синхронизация
- Список сотрудников на вкладке "Payroll" обновляется автоматически при добавлении нового сотрудника
- Не требуется перезапуск приложения
- Сохранение текущего выбора при обновлении

### 💾 Автосохранение истории часов
- Все отработанные часы автоматически сохраняются в базу данных при генерации PDF
- Полная история работы каждого сотрудника
- Защита от потери данных

### 📥 Экспорт истории в CSV
- Новое меню **Export** → **Export work hours**
- Просмотр всей истории отработанных часов
- Экспорт в Excel-совместимый CSV формат
- Статистика: общее количество часов, записей и сумм
- Возможность открыть файл сразу после экспорта

## 🔧 Технические детали

### Системные требования
- **ОС:** Windows 10/11 (64-bit)
- **Место на диске:** ~100 МБ
- **Память:** 4 ГБ RAM (рекомендуется)

### Установка

#### Автоматическая установка (рекомендуется)
1. Скачайте `PayrollSystem_v1.9.0_Setup.exe`
2. Запустите установщик
3. Следуйте инструкциям мастера установки
4. Выберите дополнительные опции:
   - Создать ярлык на рабочем столе
   - Запускать при старте Windows (опционально)

#### Portable версия
1. Скачайте `PayrollSystem.exe` из папки `dist`
2. Скопируйте в любую папку
3. Запустите двойным кликом

### Расположение файлов

#### Программа
- **Установленная версия:** `%LOCALAPPDATA%\Programs\PayrollSystem\`
- **Portable версия:** Папка, куда вы скопировали EXE

#### База данных
- **Путь:** `%LOCALAPPDATA%\PayrollSystem\payroll.db`
- **Резервные копии:** `%LOCALAPPDATA%\PayrollSystem\backups\`

#### PDF отчёты
- **Путь:** `%USERPROFILE%\Documents\PayrollSystem\Payroll\YYYY-MM\`
- Организованы по месяцам

#### Экспорт CSV
- **По умолчанию:** Предлагается сохранить в любую папку
- **Формат имени:** `hours_history_YYYYMMDD_HHMMSS.csv`

## 🚀 Быстрый старт

### Первый запуск
1. Установите приложение
2. Запустите PayrollSystem
3. Перейдите на вкладку **Employees**
4. Добавьте первого сотрудника

### Расчёт зарплаты
1. Перейдите на вкладку **Payroll**
2. Выберите сотрудника
3. Выберите период (From/To)
4. Нажмите **⚡ Generate Period**
5. Введите часы для каждого дня (двойной клик)
6. Выберите тип ставки (Fixed/Custom)
7. Введите удержания (если есть)
8. Создайте PDF (Preview/Save/Print)

### Просмотр истории часов
1. Меню **Export** → **Export work hours**
2. Просмотрите все записи
3. Нажмите **📥 Export to CSV** для экспорта

## 📝 Обновление с предыдущей версии

### Автоматическое обновление
1. Запустите новый установщик `PayrollSystem_v1.9.0_Setup.exe`
2. Установщик автоматически обновит приложение
3. Все данные (база, настройки, отчёты) сохранятся

### Ручная установка
1. Закройте старую версию приложения
2. Установите новую версию
3. Запустите приложение
4. Все данные останутся на месте

### Резервное копирование (рекомендуется)
Перед обновлением создайте копию:
1. Откройте `%LOCALAPPDATA%\PayrollSystem\`
2. Скопируйте `payroll.db` в безопасное место
3. При необходимости можно восстановить
