# 📊 Excel Import Feature - User Guide

## Обзор

Функция импорта из Excel позволяет:
- ✅ Загрузить данные о сотрудниках и отработанных часах из Excel файла
- ✅ Автоматически создать/обновить сотрудников в базе данных
- ✅ Автоматически сгенерировать зарплатные ведомости (PDF) для всех сотрудников
- ✅ Сохранить историю часов в базу данных

---

## 📋 Формат Excel файла

### Обязательные колонки

| Колонка | Название | Тип данных | Описание |
|---------|----------|------------|----------|
| A | Employee Name | Текст | Полное имя сотрудника |
| B | Hourly Rate | Число | Ставка за час (€/h) |
| C | Bank | Текст | Название банка (опционально) |
| D | IBAN | Текст | IBAN счёта (опционально) |
| E | BIC | Текст | BIC код банка (опционально) |
| F+ | DD-MM-YYYY | Число | Даты с количеством отработанных часов |

### Формат дат

Даты в заголовках колонок должны быть в одном из форматов:
- `DD-MM-YYYY` (например: 01-05-2026)
- `DD/MM/YYYY` (например: 01/05/2026)
- `DD.MM.YYYY` (например: 01.05.2026)

### Пример структуры

```
| Employee Name | Hourly Rate | Bank       | IBAN                | BIC         | 01-05-2026 | 02-05-2026 | 03-05-2026 |
|---------------|-------------|------------|---------------------|-------------|------------|------------|------------|
| John Doe      | 12.50       | ABC Bank   | DE89370400440532... | COBADEFFXXX | 8.0        | 10.0       | 8.0        |
| Jane Smith    | 15.00       | XYZ Bank   | DE89370400440533... | COBADEFFYYY | 8.5        | 9.0        | 8.0        |
```

## 🚀 Как использовать

### Шаг 1: Подготовка Excel файла

**Вариант А: Использовать шаблон**
1. Откройте PayrollSystem
2. Меню **Import** → **Import from Excel**
3. Нажмите кнопку **📖 Template**
4. Сохраните шаблон на компьютер
5. Откройте шаблон в Excel и заполните своими данными

**Вариант Б: Создать файл вручную**
1. Создайте новый Excel файл
2. Добавьте заголовки колонок (см. формат выше)
3. Заполните данные сотрудников
4. Добавьте колонки с датами и часами

### Шаг 2: Импорт данных

1. Откройте PayrollSystem
2. Меню **Import** → **Import from Excel**
3. Нажмите **📁 Browse...**
4. Выберите ваш Excel файл
5. Данные автоматически загрузятся и отобразятся в таблице

### Шаг 3: Проверка данных (вкладка Preview Data)

В таблице отобразятся:
- **Employee** - имя сотрудника
- **Rate (€/h)** - ставка за час
- **Bank** - банковские данные
- **Total Hours** - общее количество часов
- **Period** - диапазон дат
- **Gross Amount (€)** - сумма до вычетов

Проверьте, что все данные корректны!

### Шаг 4: Настройки генерации (вкладка Generation Settings)

#### Rate Type
- **Fixed Rate** - использовать фиксированную ставку (8 €/h) для всех
- **Custom Rate** - использовать ставки из Excel файла (рекомендуется)

#### Deductions
- **Utilities (€)** - вычеты за коммунальные услуги
- **Rental (€)** - вычеты за аренду

#### Output Options
- ✅ **Save hours to database** - сохранить часы в БД (рекомендуется)
- ✅ **Generate PDF files** - создать PDF файлы (рекомендуется)
- ✅ **Update existing employees** - обновить данные существующих сотрудников

### Шаг 5: Генерация

1. Нажмите **⚡ Generate All Payrolls**
2. Подтвердите действие
3. Дождитесь завершения (прогресс отображается внизу)
4. Готово! PDF файлы сохранены в `Documents\PayrollSystem\Payroll\YYYY-MM\`

## ⚙️ Настройки генерации

### Rate Type

**Fixed Rate**
- Использует фиксированную ставку 8 €/h для всех сотрудников
- Игнорирует ставки из Excel файла
- Применяются вычеты (utilities + rental)

**Custom Rate** (рекомендуется)
- Использует индивидуальные ставки из Excel файла
- Разные ставки для разных сотрудников
- Применяются вычеты (utilities + rental)

### Deductions (Вычеты)

Вычеты применяются ко всем сотрудникам:
- **Utilities** - коммунальные услуги
- **Rental** - аренда жилья

Итоговая формула: `NET = GROSS - Utilities - Rental`

### Output Options

**Save hours to database**
- ✅ Включено: Все часы сохраняются в таблицу `work_hours`
- ❌ Выключено: Часы не сохраняются (только PDF)

**Generate PDF files**
- ✅ Включено: Создаются PDF файлы для каждого сотрудника
- ❌ Выключено: PDF не создаются (только сохранение в БД)

**Update existing employees**
- ✅ Включено: Обновляются rate, bank, IBAN, BIC существующих сотрудников
- ❌ Выключено: Существующие сотрудники не изменяются

## 📁 Куда сохраняются файлы

### PDF отчёты
```
%USERPROFILE%\Documents\PayrollSystem\Payroll\YYYY-MM\
```

Пример:
```
C:\Users\YourName\Documents\PayrollSystem\Payroll\2026-05\
  ├── John Doe_Custom_12.50€h.pdf
  ├── Jane Smith_Custom_15.00€h.pdf
  └── ...
```

### База данных
```
%LOCALAPPDATA%\PayrollSystem\payroll.db
```

Таблицы:
- `employees` - данные сотрудников
- `work_hours` - история отработанных часов

## ✅ Валидация данных

Система автоматически проверяет:

### Структура файла
- ✅ Наличие обязательных колонок (Name, Rate)
- ✅ Наличие хотя бы одной колонки с датой
- ✅ Минимум 6 колонок

### Данные сотрудников
- ✅ Имя не пустое
- ✅ Ставка > 0
- ✅ Ставка - это число

### Часы работы
- ✅ Часы >= 0
- ✅ Часы <= 24
- ✅ Часы - это число

### Даты
- ✅ Корректный формат даты
- ✅ Валидная дата (существует в календаре)

Если валидация не проходит, система покажет сообщение об ошибке с указанием проблемы.

## ❗ Важные замечания

### Создание новых сотрудников
- Если сотрудник с таким именем не существует, он будет создан автоматически
- Имя сотрудника - уникальный идентификатор

### Обновление существующих сотрудников
- При включённой опции "Update existing employees":
  - Обновляется ставка
  - Обновляются банковские данные
- При выключенной опции:
  - Используются текущие данные из БД
  - Excel данные игнорируются

### Дубликаты данных
- Система предотвращает дубликаты часов (employee_id + date - уникальны)
- При повторном импорте тех же дат, часы будут обновлены

### Производительность
- Генерация может занять время при большом количестве сотрудников
- Прогресс отображается внизу окна
- Не закрывайте окно до завершения!

## 🐛 Устранение проблем

### "Неверная структура файла"
**Причина:** Неправильный формат Excel
**Решение:** 
1. Используйте шаблон (кнопка Template)
2. Проверьте названия колонок
3. Убедитесь, что первые 2 колонки - Name и Rate

### "Не найдено колонок с датами"
**Причина:** Даты в неправильном формате
**Решение:**
1. Используйте формат DD-MM-YYYY (например: 01-05-2026)
2. Не используйте кириллицу в названиях колонок с датами

### "Неверная ставка"
**Причина:** В колонке Rate не числа
**Решение:**
1. Проверьте, что колонка Rate содержит только числа
2. Используйте точку как разделитель (12.50, не 12,50)

### "Неверное значение часов"
**Причина:** В ячейках с часами не числа или некорректные значения
**Решение:**
1. Часы должны быть от 0 до 24
2. Используйте точку как разделитель (8.5, не 8,5)
3. Пустые ячейки допустимы (0 часов)

## 💡 Советы и рекомендации

### Организация данных
1. Держите один Excel файл на месяц
2. Называйте файлы понятно: `payroll_2026-05.xlsx`
3. Делайте резервные копии Excel файлов

### Перед импортом
1. Проверьте данные в Excel визуально
2. Убедитесь, что все ставки корректны
3. Проверьте суммы часов

### После импорта
1. Откройте несколько PDF файлов для проверки
2. Сверьте суммы с ожидаемыми
3. Проверьте историю часов: **Export** → **Export work hours**

### Массовые операции
- Можно импортировать данные за несколько месяцев
- Система автоматически рассортирует PDF по папкам (по месяцам)
- Используйте фильтры в Excel перед экспортом

## 📚 Примеры использования

### Пример 1: Стандартная зарплата за месяц

**Задача:** Выплатить зарплату 10 сотрудникам за май 2026

**Шаги:**
1. Создайте Excel файл с 10 сотрудниками
2. Добавьте колонки с датами с 01-05-2026 по 31-05-2026
3. Заполните часы для каждого дня
4. Импортируйте → Настройки: Custom Rate, без вычетов
5. Generate All Payrolls

**Результат:** 10 PDF файлов в `Documents\PayrollSystem\Payroll\2026-05\`

### Пример 2: Частичная занятость

**Задача:** Оплатить нескольким сотрудникам работу на выходных

**Шаги:**
1. Создайте Excel только с выходными днями (например: 03-05, 04-05, 10-05, 11-05)
2. Укажите только нужных сотрудников
3. Импортируйте → Generate

**Результат:** PDF только для работавших сотрудников, только за отработанные дни

### Пример 3: Разные ставки и вычеты

**Задача:** У сотрудников разные ставки, всем вычесть 50€ utilities

**Шаги:**
1. В Excel укажите индивидуальные ставки для каждого
2. Импортируйте
3. Настройки: Custom Rate, Utilities = 50.00
4. Generate

**Результат:** У каждого своя ставка, но у всех вычтено 50€
