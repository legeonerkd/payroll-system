# Новые функции версии 1.9.0

## 🔄 Автоматическое обновление списка сотрудников

### Проблема (до версии 1.9.0)
При добавлении нового сотрудника на вкладке **Employees**, для того чтобы он появился в списке на вкладке **Payroll**, требовалось перезапустить приложение.

### Решение (версия 1.9.0)
Теперь список сотрудников обновляется **автоматически**:

1. Откройте вкладку **Employees**
2. Добавьте нового сотрудника (кнопка **➕ Add**)
3. Перейдите на вкладку **Payroll**
4. ✅ Новый сотрудник уже доступен в выпадающем списке!

**Бонус:** Если у вас был выбран сотрудник, он останется выбранным после обновления.

## 💾 Автоматическое сохранение истории часов

### Как это работает
При генерации любого отчёта (Preview, Save или Print), все введённые часы **автоматически сохраняются** в базу данных.

### Что сохраняется
- Имя сотрудника
- Дата работы
- Количество отработанных часов
- Ставка сотрудника

### Преимущества
- 📊 Полная история всех отработанных часов
- 🔍 Возможность анализа данных за любой период
- 💾 Автоматическое резервное копирование данных
- 📥 Экспорт в удобные форматы

---

## 📥 Экспорт истории часов в CSV

### Как использовать

#### Шаг 1: Открыть окно экспорта
1. В главном меню выберите **Export** → **Export work hours**
2. Откроется окно с таблицей всех отработанных часов

#### Шаг 2: Просмотр данных
В таблице отображаются:
- **Employee** - имя сотрудника
- **Date** - дата работы (формат: ДД-ММ-ГГГГ)
- **Hours** - количество часов
- **Rate (€/h)** - ставка за час
- **Amount (€)** - сумма за этот день

#### Шаг 3: Статистика
Внизу окна показывается:
- **Total records** - общее количество записей
- **Total hours** - суммарное количество часов
- **Total amount** - общая сумма в евро

#### Шаг 4: Экспорт
1. Нажмите кнопку **📥 Export to CSV**
2. Выберите место сохранения файла
3. Файл будет сохранён с именем вида: `hours_history_YYYYMMDD_HHMMSS.csv`
4. Система предложит открыть файл сразу после экспорта

### Формат CSV файла
```csv
Employee,Date,Hours,Rate (€/h),Amount (€)
John Doe,2026-05-20,10.0,8.00,80.00
Jane Smith,2026-05-20,8.5,12.50,106.25
...
```

### Использование в Excel
CSV файл можно открыть в Microsoft Excel, Google Sheets или LibreOffice Calc:
- Все колонки будут автоматически разделены
- Можно создавать сводные таблицы
- Можно строить графики и диаграммы
- Можно фильтровать и сортировать данные

## 🎨 Улучшения интерфейса

### Zebra-стиль таблиц
Все таблицы теперь имеют чередующиеся цвета строк для удобства чтения:
- Светло-серые строки (#f9f9f9)
- Белые строки (#ffffff)

## 💡 Советы по использованию

### Резервное копирование данных
Регулярно экспортируйте историю часов в CSV для:
- Создания резервных копий
- Отправки данных бухгалтеру
- Анализа производительности
- Архивирования старых данных

### Проверка данных
Перед отправкой отчёта:
1. Откройте окно экспорта часов
2. Проверьте последние записи
3. Убедитесь, что все часы сохранены корректно

### Автоматическое сохранение
Помните: часы сохраняются **только при генерации PDF**. Если вы:
- Ввели часы
- Но не создали отчёт (Preview/Save/Print)
- То эти часы **не будут сохранены** в базу данных
