## 📊 Точная структура файла

### Формат: Excel (.xlsx или .xls)

### Обязательные колонки (A-E):

| Колонка | Название          | Тип       | Обязательно | Пример                    |
|---------|-------------------|-----------|-------------|---------------------------|
| **A**   | Employee Name     | Текст     | ✅ ДА       | John Doe                  |
| **B**   | Hourly Rate       | Число     | ✅ ДА       | 12.50                     |
| **C**   | Bank              | Текст     | ❌ Нет      | ABC Bank                  |
| **D**   | IBAN              | Текст     | ❌ Нет      | DE89370400440532013000    |
| **E**   | BIC               | Текст     | ❌ Нет      | COBADEFFXXX               |

### Колонки с датами (F, G, H...):

| Колонка | Формат заголовка  | Значение  | Пример заголовка | Пример значения |
|---------|-------------------|-----------|------------------|-----------------|
| **F+**  | DD-MM-YYYY        | Число     | 01-05-2026       | 8.0             |

## ⚙️ Детальные требования

### 1. Employee Name (Колонка A)

**Формат:** Любой текст

**Требования:**
- ✅ Не должно быть пустым
- ✅ Это уникальный идентификатор сотрудника
- ✅ Используется для поиска существующего сотрудника в БД

**Примеры:**
```
✅ John Doe
✅ Jane Smith
✅ Иван Петров
✅ Employee #123
❌ (пустая ячейка)
```

### 2. Hourly Rate (Колонка B)

**Формат:** Число (decimal)

**Требования:**
- ✅ Должно быть больше 0
- ✅ Используйте точку как разделитель (12.50, не 12,50)
- ✅ Максимум 2 знака после запятой

**Примеры:**
```
✅ 8
✅ 12.5
✅ 12.50
✅ 15.00
❌ 0
❌ -5
❌ 12,50  (запятая вместо точки)
❌ текст
```

### 3. Bank (Колонка C) - опционально

**Формат:** Текст

**Требования:**
- ❌ Может быть пустым
- ✅ Любое название банка

**Примеры:**
```
✅ ABC Bank
✅ Sberbank
✅ Deutsche Bank
✅ (пустая ячейка)
```

### 4. IBAN (Колонка D) - опционально

**Формат:** Текст

**Требования:**
- ❌ Может быть пустым
- ✅ Любой формат (валидация не проводится)

**Примеры:**
```
✅ DE89370400440532013000
✅ GB29NWBK60161331926819
✅ (пустая ячейка)
```

### 5. BIC (Колонка E) - опционально

**Формат:** Текст

**Требования:**
- ❌ Может быть пустым
- ✅ Любой формат (валидация не проводится)

**Примеры:**
```
✅ COBADEFFXXX
✅ NWBKGB2L
✅ (пустая ячейка)
```

### 6. Даты (Колонки F, G, H...)

**Формат заголовка:** DD-MM-YYYY, DD/MM/YYYY или DD.MM.YYYY

**Поддерживаемые форматы:**
```
✅ 01-05-2026  (дефис)
✅ 01/05/2026  (слэш)
✅ 01.05.2026  (точка)
❌ 2026-05-01  (неправильный порядок)
❌ 1 мая 2026  (текст)
```

**Формат значения:** Число (часы)

**Требования:**
- ✅ От 0 до 24
- ✅ Дробные значения разрешены (8.5)
- ❌ Пустые ячейки = 0 часов (день не будет сохранён)

**Примеры значений:**
```
✅ 0     (0 часов, день пропускается)
✅ 8     (8 часов)
✅ 8.0   (8 часов)
✅ 8.5   (8.5 часов)
✅ 10    (10 часов)
✅ 24    (24 часа)
✅ (пустая) (пропускается)
❌ -1    (отрицательное)
❌ 25    (больше 24)
❌ текст
```

```
❌ 1/5/26          (короткий год)
```

## 🎨 Как создать файл в Excel

### Вариант 1: Использовать готовый шаблон (РЕКОМЕНДУЕТСЯ)

1. Откройте PayrollSystem
2. **Import** → **Import from Excel**
3. Нажмите **📖 Template**
4. Сохраните файл
5. Откройте в Excel
6. Замените примеры на свои данные
7. Сохраните
8. Импортируйте!

### Вариант 2: Создать вручную в Excel

**Шаг 1:** Создайте новый Excel файл

**Шаг 2:** В первой строке (заголовки) напишите:
```
A1: Employee Name
B1: Hourly Rate
C1: Bank
D1: IBAN
E1: BIC
F1: 01-05-2026
G1: 02-05-2026
H1: 03-05-2026
...
```

**Шаг 3:** Начиная со второй строки, добавьте данные сотрудников:
```
A2: John Doe
B2: 12.50
C2: ABC Bank
D2: DE89370400440532013000
E2: COBADEFFXXX
F2: 8
G2: 10
H2: 8
...
```

**Шаг 4:** Сохраните как `.xlsx`

**Шаг 5:** Импортируйте через PayrollSystem

## ✅ Чек-лист перед импортом

Проверьте:
- [ ] Файл имеет расширение `.xlsx` или `.xls`
- [ ] Первая строка - это заголовки
- [ ] Колонка A: Employee Name (не пустая)
- [ ] Колонка B: Hourly Rate (число > 0)
- [ ] Колонки C, D, E: Bank, IBAN, BIC (могут быть пустыми)
- [ ] Колонки F+: Даты в формате DD-MM-YYYY
- [ ] Значения часов: числа от 0 до 24
- [ ] Использовали точку (не запятую) для дробных чисел
- [ ] Нет кириллицы в названиях колонок с датами
- [ ] Хотя бы один сотрудник имеет хотя бы одну запись часов

## 🔍 Частые ошибки

### ❌ "Неверная структура файла"

**Проблема:** Неправильные названия колонок

**Решение:**
- Колонка A должна содержать слово "name" или "employee"
- Колонка B должна содержать слово "rate" или "hourly"
- Используйте готовый шаблон!

### ❌ "Не найдено колонок с датами"

**Проблема:** Даты в неправильном формате

**Решение:**
- Используйте DD-MM-YYYY (01-05-2026)
- НЕ используйте текст ("1 мая")
- НЕ используйте YYYY-MM-DD

### ❌ "Неверная ставка"

**Проблема:** В колонке Rate не число

**Решение:**
- Проверьте, что там числа, не текст
- Используйте точку: 12.50 (НЕ 12,50)

### ❌ "Неверное значение часов"

**Проблема:** Часы меньше 0 или больше 24

**Решение:**
- Часы должны быть 0-24
- Используйте точку для дробных: 8.5
