# 🚀 Быстрый старт: Импорт из Excel

## В двух словах

**Формат файла:** Excel (`.xlsx`)

**Структура:**
```
Колонка A: Employee Name    (обязательно)
Колонка B: Hourly Rate      (обязательно)
Колонка C: Bank              (опционально)
Колонка D: IBAN              (опционально)
Колонка E: BIC               (опционально)
Колонка F+: DD-MM-YYYY       (даты с часами)
```

---

## 📋 Минимальный пример

### Excel файл должен выглядеть так:

```
┌─────────────────┬─────────────┬──────┬──────┬─────┬────────────┬────────────┐
│ Employee Name   │ Hourly Rate │ Bank │ IBAN │ BIC │ 01-05-2026 │ 02-05-2026 │
├─────────────────┼─────────────┼──────┼──────┼─────┼────────────┼────────────┤
│ John Doe        │ 12.50       │      │      │     │ 8          │ 10         │
└─────────────────┴─────────────┴──────┴──────┴─────┴────────────┴────────────┘
```

**Это всё!** Система поймёт такой файл.

---

## ⚡ 3 простых шага

### Шаг 1: Получите шаблон
1. Откройте PayrollSystem
2. **Import** → **Import from Excel**
3. Нажмите **📖 Template**
4. Сохраните файл `payroll_template.xlsx`

### Шаг 2: Заполните данные
1. Откройте шаблон в Excel
2. Замените примеры на своих сотрудников
3. Укажите отработанные часы для каждого дня
4. Сохраните файл

### Шаг 3: Импортируйте
1. В PayrollSystem: **Import** → **Import from Excel**
2. Нажмите **📁 Browse...**
3. Выберите ваш файл
4. Проверьте данные в таблице
5. Нажмите **⚡ Generate All Payrolls**

**Готово!** PDF файлы созданы в `Documents\PayrollSystem\Payroll\`

## ✅ Правильно

### Даты в заголовках:
```
✅ 01-05-2026
✅ 02-05-2026
✅ 15-12-2026
```

### Ставка:
```
✅ 8
✅ 12.5
✅ 15.00
```

### Часы:
```
✅ 0      (день не будет сохранён)
✅ 8      (8 часов)
✅ 8.5    (8 с половиной часов)
✅ 24     (максимум)
✅ (пусто) (день пропускается)
```

---

## ❌ Неправильно

### Даты:
```
❌ 2026-05-01   (год первым - неправильный порядок)
❌ 1 мая        (текст вместо даты)
❌ May 1        (английский текст)
```

### Ставка:
```
❌ 12,50   (запятая вместо точки)
❌ 0       (должна быть больше 0)
❌ -5      (отрицательная)
```

### Часы:
```
❌ -1     (отрицательные)
❌ 25     (больше 24)
❌ текст  (должно быть число)
```

## 💡 Частые вопросы

### Можно ли импортировать разные периоды?
✅ **Да!** Просто добавьте колонки с нужными датами.

### Можно ли частично заполнять часы?
✅ **Да!** Пустые ячейки = 0 часов (день пропускается).

### Можно ли обновить существующих сотрудников?
✅ **Да!** В настройках включите "Update existing employees".

### Что если сотрудник уже есть в базе?
✅ Система найдёт его по имени и обновит или оставит без изменений (зависит от настроек).

### Можно ли использовать запятую в числах?
❌ **Нет!** Только точка: `12.50` (не `12,50`)

### Сколько сотрудников можно импортировать за раз?
✅ **Сколько угодно!** Система обработает всех.

### Импорт не работает?
1. Используйте готовый шаблон
2. Проверьте формат дат (DD-MM-YYYY)
3. Проверьте что используете точку в числах
